# Скинемся — контекст проекта

Веб-приложение для деления общих трат в компании (поездки, бани, встречи, совместные закупки). Автор: Виталий.

## Где что лежит

- **Сайт (для себя и друзей):** https://v1147277.github.io/skinemsya/
- **Репозиторий GitHub:** https://github.com/v1147277/skinemsya (файлы `index.html`, `sw.js`, `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`)
- **Обновить сайт:** https://github.com/v1147277/skinemsya/upload/main → перетащить `index.html` (и `sw.js`/иконки/манифест, если менялись) → Commit changes
- **Рабочие файлы на Mac:** Загрузки → skinemsya (`index.html`, `sw.js`, манифест и 3 иконки)
- **Копия вашей первой поездки:** `skinemsya-poezdka.json` (загружается кнопкой «Загрузить из копии»)
- Netlify не подошёл: аккаунт блокируется сразу после регистрации.

## Как устроено

- `index.html` (всё внутри) + `sw.js` для работы без интернета (кэш v3) + `manifest.webmanifest` и иконки PNG 180/192/512 для установки на экран «Домой».
- Данные хранятся только в браузере телефона (localStorage), без сервера. Резервная копия — JSON-файл.
- Тема: светлая / тёмная / как в телефоне. Шрифты Unbounded и Manrope, цвета: синий #3b4bf5, жёлтый #ffd43b, коралловый #ff7a59, мятный #2bd4a4.
- Защита: Content-Security-Policy в `<head>` (скрипты только свои, шрифты только Google Fonts, никаких внешних запросов). Если понадобится внешний сервис — правило нужно расширить.

## Что умеет (текущая версия)

- **Главный экран:** если мероприятия уже есть — кнопка «+ Новое мероприятие» (форма «Новая тусовка» раскрывается по нажатию, «Свернуть»), сразу под ней фильтр в одну прокручиваемую строку и список; статистика — после списка. Праздничный блок «Новая тусовка», кнопка «История», фильтр «Показать» — одна кнопка «Показать: Все мероприятия ▾», по нажатию список вариантов с числом мероприятий (все, избранное, месяц, прошлый месяц, год, период, «Выбранные мероприятия» — конкретные мероприятия с поиском, выбор сохраняется); под фильтром поле **поиска по словам** (название, описание, отзывы, имена участников, «За что»; все слова должны найтись; ё=е; работает вместе с фильтром; список, «потрачено» и «Статистика» — только по найденному; кнопка «Выбрать из найденных для статистики» открывает «Выбрать» с отмеченными найденными), кнопка «?» с инструкцией, переключатель темы, резервная копия.
- **Изменение названия, дат, описания:** нажатие на название в шапке мероприятия (под датами подпись «изменить») → окно «Мероприятие» с проверкой пустого названия и автозаменой перепутанных дат; дублируется на вкладке «Люди».
- **Мероприятие:** даты «с–по», бюджет, описание, избранное ★, оценка смайликом, отзывы «Что понравилось / не понравилось».
- **Участник (нажать на имя во вкладке «Люди»):** имя, доля (0,5 / 1 / 1,5 / 2 / 3 / 4 / 5 — пара, ребёнок), реквизиты для перевода (телефон СБП / карта, банк). Реквизиты подставляются в новые мероприятия по совпадению имени.
- **Несколько плательщиков** в одном расходе («Платили несколько человек»), в списке «Вася + Коля». При удалении участника из такого расхода убирается только его доля.
- **Удаление мероприятия:** красная корзина на каждой карточке в списке «История» (внизу справа) и в шапке открытого мероприятия рядом со звёздочкой, плюс ссылка на вкладке «Люди» → окно «Удалить мероприятие?» с названием, датами, суммой, числом людей и расходов → «Удалить навсегда» / «Отмена». После удаления 10 секунд внизу висит кнопка «Вернуть».
- **Вкладки (с 02.10.2026):** нижняя панель с иконками — Расходы · Мои · Люди · Итог (на «Итоге» красная цифра — сколько переводов осталось). Выбранная вкладка — синий цвет на светлой подложке. Вкладки «Переводы» больше нет: ручные переводы и «Уже переведено» — в «Итоге», блок «Переводы» под «Сбором денег».
- **Добавление расхода:** жёлтая круглая кнопка «+» справа внизу на вкладке «Расходы» → окно снизу: сначала сумма (крупно), ниже «Кто платил» (по умолчанию «это я» из «Моих»), категории, «За что», «На кого делим», «Добавить/Отмена». Нажатие на расход открывает то же окно для правки. Закрывается «Отменой», тапом по затемнению, Esc и кнопкой «Назад» на Android.
- **Расходы:** список «Расходы · N»; если расходов нет — кнопка «Добавьте первый расход» (открывает окно расхода), без участников — «Сначала добавьте участников →». Своё окно выбора плательщика, несколько категорий на расход (поровну или вручную), «На кого делим» с кнопкой «Все», редактирование, кнопка «Итог →» в конце.
- **Категории:** Без категории, Продукты, Алкоголь, Транспорт, Жильё, Ресторан; под «Ещё»: Баня, Экскурсии, Развлечения, Совместные закупки, Допы.
- **Мои:** личный журнал трат, «Личное», перенос в общие, «Вернуть в журнал».
- **Итог (порядок с 02.10.2026):** Осталось перевести → Баланс каждого → Сбор денег → Отправить в чат → Как прошло? → свёрнутый блок «Аналитика» (сводка в заголовке; внутри План и факт, По категориям, На 1 чел., Сравнить с прошлым; раскрыт/свёрнут — запоминается). Детали блоков: Осталось перевести (округление «Точно / до 10 / до 100 ₽», реквизиты получателя, кнопки «Напомнить», «Реквизиты», «Оплачено») → Отправить в чат (одна кнопка «Поделиться» → меню: текстом / картинкой / ссылкой / таблицей Excel; текст можно посмотреть под кнопкой) → Сравнить с прошлым (вывод «Вы потратили больше/меньше», на человека, что изменилось сильнее всего; «Поделиться сравнением» → картинкой или файлом Excel: вывод + таблица «Сейчас / Тогда / Разница / %») → Как прошло?
- **Ссылка на мероприятие:** всё мероприятие сжато в саму ссылку (#e=…), без сервера. Получатель видит окно «Добавить к себе / Обновить моё». В ссылку не идут «Мои», избранное. Ограничение: длинная ссылка (>4000 символов) может не влезть в сообщение Telegram.
- **Таблица Excel:** настоящий .xlsx, собирается в браузере без библиотек (листы «Итог», «Расходы», «Уже переведено»; для статистики — «Мероприятия», «Расходы»). Суммы — числа с форматом, текст хранится как текст, формулой стать не может. Имя файла латиницей.
- **Картинки** (итог и сравнение) — в текущей теме приложения: светлая/тёмная/как в телефоне. Сразу открывается меню «Поделиться»; если телефон не умеет — картинка показывается с кнопками «Отправить» и «Сохранить».
- **Главный экран:** красное напоминание о копии (если были изменения и копии нет 14 дней, «Позже» = 3 дня); «Статистика» по отфильтрованным мероприятиям (категории, люди: заплатил / его часть); «+ Участники из прошлого мероприятия» (образец: люди, доли, реквизиты, план по категориям, округление).
- **Кнопка «Назад» на Android:** закрывает окно или возвращает из мероприятия/инструкции на главный.
- Открытие мероприятия: на «Итоге», если последний день прошёл или дат нет, но расходы есть; иначе (сегодня, будущее, новое без расходов) — на «Расходах».
- **Справка «?» (с 03.10.2026):** по лучшим практикам — поиск по справке, оглавление-кнопки по задачам, «Быстрый старт», 10 разделов-задач («Создать мероприятие», «Добавить расход», «Доли и реквизиты», «Кто кому переводит», «Поделиться», «Аналитика и сравнение», «Мои», «Фильтр, поиск, статистика», «Копия и данные», «Частые вопросы»). В разделах скриншоты приложения на демо-данных (Вася, Петя, Коля, Аня) с оранжевыми номерами, совпадающими с номерами шагов; у картинок подписи для незрячих. Картинки в теме приложения (светлая/тёмная), WebP внутри index.html (≈400 КБ из ~730 КБ файла), подставляются только при открытии справки. При изменении интерфейса скриншоты нужно переснять (скрипт cap.js в рабочей папке Claude).
- **Отмена действий:** удаление расхода, перевода, участника, записи «Моих» и нажатие «Оплачено» можно отменить кнопкой «Вернуть» (10 секунд). Крестики удаления — зона нажатия 44×44 px.
- **Суммы:** текстовые поля с цифровой клавиатурой (inputmode="decimal"), принимают запятую и точку, лишние символы отсекаются при вводе.
- **Контраст (светлая тема):** зелёный #0b7a3c, красный #bf2a30 — не ниже 4,5:1 на плашках и белом фоне.
- Защита: очистка данных из файлов копии, проверка сумм (больше 0 и меньше 1 млрд ₽), ограничение длины полей, подтверждение удаления участника и мероприятия, предупреждение, если браузер не сохранил данные.

## История правок

- 03.10.2026: жалоба «из Safari не добавляется ярлык». Причины: манифест был вшит как data:-ссылка с неверным start_url и одной иконкой; не было подсказки в приложении; в iOS 26 «Поделиться» спрятано под «⋯»; во встроенных браузерах (Telegram, Instagram, VK) пункта «На экран „Домой“» нет. Сделано: отдельные манифест и иконки, карточка «Установить на iPhone/телефон» на главном (шаги под iOS, подсказка для встроенных браузеров и Chrome на iPhone, кнопка «Установить» на Android, «Больше не показывать»), раздел справки «Установить на телефон» с блоком «Особенности iPhone» (отдельное хранилище Safari и приложения, перенос копией). Chrome: ошибок установки нет.
- 01.10.2026: главный экран не помещался на смартфоне (логотип + «?» + тема ≈ 390 px при экране 360 px). Логотип и кнопки ужимаются, проверено на 320 и 360 px. Заодно: даты в одну колонку на узких экранах, суммы не разрываются, сегодняшняя дата по местному времени, лимиты длины полей, CSP, `sw.js` → кэш v2.
- 01.10.2026: корзина для удаления мероприятия с окном подтверждения и кнопкой «Вернуть»; корзина и на карточках списка «История». Мероприятие без дат с расходами открывается на «Итоге».
- 01.10.2026: добавлены доли, реквизиты, напоминание должнику, ссылка на мероприятие, напоминание о копии, таблица для Excel, несколько плательщиков, «по образцу», статистика, округление переводов, «Назад» на Android (по сравнению со Splitwise, Tricount, Settle Up, Splid). Отложено: расходы в валюте (курс вручную), фото чеков (мало памяти браузера).
- 02.10.2026: аудит интерфейса — Итог: главное наверх, аналитика свёрнута; главный экран: список вместо формы; «Вернуть» после удалений; контраст; поля сумм с запятой. Проверка безопасности после этого: атаки через ссылку (15/15), вредный код во всех новых окнах — не выполняется; найдено и исправлено: очень длинное слово без пробелов раздвигало экран (теперь переносится).
